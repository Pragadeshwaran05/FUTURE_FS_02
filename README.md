# 🚀 LeadFlow CRM

A modern Customer Relationship Management (CRM) system built using **Flask** and **SQLite** to help businesses manage leads, customers, reports, and business operations efficiently.

---

## 📌 Features

- 🔐 Secure Admin Login
- 📊 Interactive Dashboard
- 👥 Customer Management
- 📋 Lead Management
- 📈 Reports & Analytics
- ⚙️ Admin Profile Management
- 🔒 Change Password
- 🎨 Light & Dark Theme
- 📱 Responsive Design
- 📞 Contact Form
- 💾 Database Backup
- ✨ Modern Animated UI

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Pragadeshwaran05/FUTURE_FS_02.git
```

Move to the project folder:

```bash
cd FUTURE_FS_02
```

---

### Create Virtual Environment

```bash
python -m venv venv
```

Activate it:

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / macOS

```bash
source venv/bin/activate
```

---

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

### Run the Project

```bash
python app.py
```

Open:

```
http://127.0.0.1:5000
```
